# VOIDEX DATA ENGINE — DATA PROVENANCE & AUDITABILITY

## 1. Princípio "No Hallucination"

A IA do VOIDEX é estritamente proibida de preencher dados ausentes ou criar fórmulas estatísticas por inferência. Todas as estatísticas são auditáveis com fonte primária.

## 2. Níveis de Confiabilidade de Fontes

| Nível | Identificador | Tipo | Confiabilidade |
| :--- | :--- | :--- | :---: |
| **Nível 1** | `official_export` | Exportações oficiais públicas da Digital Extremes | 1.0 (100%) |
| **Nível 2** | `manual_verification` | Teste e validação in-game no Simulacrum por mantenedores | 1.0 (100%) |
| **Nível 3** | `community_api` | APIs abertas e repositórios comunitários auditados | 0.85 (85%) |
